🎨 AI Style Preview (Replicate)

Customer garment select kare aur "Generate AI Preview" click kare — AI ek realistic photo banayega. API key replicate.com/account/api-tokens se milegi.

⚠ API key kisi ko mat dikhao. Replicate pe free $5 credits milte hain (~1600 images).
📱 SMS Notifications (Fast2SMS)

Customers ko order confirmation, status updates aur OTP automatically SMS milenge. Free API key fast2sms.com pe signup karke milegi (Settings → Dev API).

⚠ SMS key kisi ko mat batao. Free tier me ~500 OTPs ya ~200 transactional SMS milte hain.
💌 Email Notifications (GoDaddy SMTP)

Email notifications are active using info@uttamtailors.in via GoDaddy SMTP. Order confirmations sent from order@uttamtailors.in, status updates from update@uttamtailors.in. No setup needed — works automatically for logged-in customers with email.

✅ Email system is configured and ready. Restart server to activate.
🔑 FCM Push Notifications (Firebase)

Push notifications for customers who visit your website and allow notifications. Free, no per-message cost.

ⓘ Go to console.firebase.google.com → Your Project → Project Settings → Service Accounts → Generate new private key → paste the entire JSON here.
ⓘ Firebase Console → Project Settings → General → Your apps → Web app → Config object.
ⓘ Firebase Console → Project Settings → Cloud Messaging → Web Push certificates → Generate key pair → copy the Key pair value.
